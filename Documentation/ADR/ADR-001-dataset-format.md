# ADR-001: binarios locales y catálogo JSON

Se conserva identidad FJ/FMA y se transforma en build-time a posiciones locales uniformes. Binario simple evita parsear OBJ en Android. Normales recalculadas, sin dependencia de importador glTF. Un provider desacopla el futuro dataset femenino. Compromiso: miles de assets; catálogo usa strings legibles y requiere validación anatómica de categorías.
